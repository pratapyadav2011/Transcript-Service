One click, every time: install the helper extension

Browsers forbid a web page from reading youtube.com cookies, so this page cannot grab them itself — the extension can, and it arrives already pointed at this server.

  1. ⬇ Download extension then unzip it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the unzipped folder.
  4. Log in to YouTube, click the extension icon, click Send cookies.

Chrome removed installing extensions from web pages in 2018, so this is the shortest path a self-hosted service can offer. Works in Edge and Firefox too.
